# 油品价差申诉与退款额度台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在「油品价格维护」基础上扩展为价差申诉与退款额度闭环，数据保存在浏览器 localStorage，重载后申诉、额度、版本关系与阻断原因保持对应。

## 业务规则

**申诉受理**（录入站点、油品、小票时间、成交价，系统核对同刻挂牌价）

命中任一阻断规则即登记为「不予受理」并持久保留阻断原因：

1. 小票时间早于该油品首次调价生效时间；
2. 小票距申诉受理超过二十四小时；
3. 与有效申诉重复（同站点、同油品、同小票时间、同成交价；已驳回/不受理单不占位）。

未命中阻断时：

- 站点当日累计退款（含本单预计价差）不超日额度、且同刻挂牌价可查 → 直接通过，冻结小票快照与当时价格版本；
- 超额，或小票同刻挂牌价缺失 → 必须填写依据，转入复核。

**复核与补证**

- 复核可通过（填复核意见）或驳回（填原因；驳回单不再占重复位与额度）；
- 挂牌价缺失单必须先补证：补证不改写历史版本，而是在小票时刻追加一个带原因、带来源单号、指向原同刻版本的新版本，应退价差随之重算；
- 复核通过时对当日额度做二次校验（可先调高站点额度），通过后冻结小票与价格版本。

**价格与额度**

- 普通调价只追加新版本，新生效时间必须晚于当前最新版本，历史版本不覆盖；
- 通过单引用的版本本体打冻结标记；
- 额度按站点、按决策当日累计，额度台实时展示已用/剩余/超限。

## 分层结构

| 层 | 目录 | 职责 |
| --- | --- | --- |
| 规则层 | `src/domain` | 类型、纯函数规则（受理评估、额度累计、版本匹配、冻结/补证判定）、种子数据，不依赖 Vue/Pinia/存储 |
| 本地档案层 | `src/archive` | localStorage 装载/保存/损坏回退/重置与 ID 生成，可平滑替换为接口 |
| 状态层 | `src/stores` | Pinia store，编排规则与档案 |
| 展示层 | `src/components`、`src/ui`、`src/App.vue` | 表单实时预判、申诉列表、额度台、版本时间线、操作流水，只做展示与交互 |

## 演示数据

首次打开自动写入 3 个站点、多版本挂牌价，以及已通过（含冻结）、超额度待复核、挂牌价缺失待补证、超 24 小时阻断、早于生效阻断五类样例单；页头「恢复演示数据」可重置。

关键路径可在界面上直接演练：对「广州三站 · 0号柴油」的缺失价待复核单执行「补证生成新版本」后再「复核通过并冻结」；或调低站点日额度制造超额复核。
