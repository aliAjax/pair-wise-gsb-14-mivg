# 价差申诉与退款额度台（油品价格维护扩展）

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务闭环

1. **申诉录入**：站点、油品、小票时间、成交价、同刻挂牌价、加油升数。
2. **受理阻断（硬规则）**：小票时间早于该油品最早挂牌价版本生效时间、距提交超过 24 小时、
   同站点 + 同油品 + 同小票时间已受理过 —— 三种情况不予受理，阻断原因留痕展示。
3. **直通过 / 复核**：站点当日累计退款不超额度且能匹配到当时挂牌价版本时直接通过；
   超额或小票时刻挂牌价版本缺失时，进入待复核，必须填写依据（缺价还须确认挂牌价）后由复核人通过或驳回。
4. **冻结**：通过时冻结小票信息与当时价格版本快照，之后改价、删价版本均不影响已通过申诉；
   被冻结引用的价格版本不可删除。
5. **补证**：已通过申诉补证不改动冻结数据，只追加一条带原因的新版本（v1 为通过时版本）。
6. **持久化**：全部数据存浏览器 localStorage，重载后申诉、额度、价格版本关系与阻断原因保持对应。

## 分层结构

- `src/domain/`：领域模型与纯规则引擎（`rules.ts`），不依赖 Vue / Pinia / localStorage，可独立单测。
- `src/archive/`：本地档案层，负责 localStorage 读写与演示种子，规则层不感知存储方式。
- `src/stores/`：Pinia 编排层，串联规则与档案。
- `src/components/`：展示层（录入表单、额度面板、申诉台账、版本台账），只通过 store 取数与操作。
